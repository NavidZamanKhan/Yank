# Assets and dependencies

The poster artwork is drawn in Flutter in `poster_artwork.dart`. The Yank mark and launcher icons are original project assets. `tool/generate_icons.py` can regenerate PNG icons with Pillow; the SVG source is in `assets/branding/`.

`assets/audio/weekend.wav` is an original synthesized instrumental sketch generated by `tool/generate_demo_audio.py` using Python's standard library. It is 24 seconds, mono, 16 kHz, 16-bit PCM. No third-party recording or voice sample is included. The original code and these original assets are supplied for reuse in Yank.

External sample links are illustrative saved items. They do not imply affiliation or live content ingestion. Document bodies and reported document/photo sizes are fixture data.
